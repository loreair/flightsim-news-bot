# FlightSim News Bot

🇮🇹 [Italiano](README.md) | 🇬🇧 English

A Telegram bot that publishes the main news from the flight simulation world (MSFS, DCS, X-Plane) **twice a week — Wednesday and Saturday morning** — with a short Italian summary generated by Claude Haiku for each article.

## How it works

1. Collects the latest articles from six sources (up to 3 per source, up to 15 in total after removing duplicates).
2. Skips links that were already sent, stored in `sent_links.json`.
3. Generates a 2-sentence Italian summary for each new article using **Claude Haiku 4.5** (Anthropic).
4. Sends the message to Telegram, automatically splitting it into multiple parts if it exceeds 4000 characters.
5. Updates `sent_links.json` (up to 500 links) and saves it in the repository via an automatic commit.

If there are no new articles, the bot still sends the opening message with a “no news” notice.

## Schedule

The bot runs on GitHub Actions **twice a week: Wednesday and Saturday at 06:30 (Rome time)**.

GitHub Actions uses UTC. The cron is set to `30 4 * * 3,6` (04:30 UTC = 06:30 CEST during daylight saving time).

> **Clock change note:** In winter (CET, UTC+1), update the cron to `30 5 * * 3,6` to keep the 06:30 Rome time.

| Day | Cron (UTC) | Rome time (CEST) |
|---|---|---|
| Wednesday | `30 4 * * 3` | 06:30 |
| Saturday | `30 4 * * 6` | 06:30 |

> GitHub may delay scheduled runs during high load periods. If the delay is excessive, trigger the run manually from Actions.

## Configuration

These secrets must be set in the repository (**Settings → Secrets and variables → Actions**):

| Secret | Description |
|---|---|
| `TELEGRAM_TOKEN` | Bot token, obtained from @BotFather |
| `TELEGRAM_CHAT_ID` | ID of the destination channel or chat |
| `ANTHROPIC_API_KEY` | Anthropic API key used for the summaries |

---

## Manual run

From GitHub: **Actions → FlightSim News Bot → Run workflow**. The message is sent to Telegram immediately.

Locally (Node.js 24):

```bash
npm install cheerio axios rss-parser @anthropic-ai/sdk
TELEGRAM_TOKEN=... TELEGRAM_CHAT_ID=... ANTHROPIC_API_KEY=... node bot.js
```
